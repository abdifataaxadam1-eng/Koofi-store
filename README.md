# Koofi Store
A responsive static affiliate-store starter for Koofi Store.

## Important
The product buttons currently contain placeholder affiliate URLs:
`YOUR_AFFILIATE_LINK_1` ... `YOUR_AFFILIATE_LINK_6`

Replace them only after your affiliate program approves your account and provides your tracking links.

## Publish free with GitHub Pages
1. Create a GitHub account.
2. Create a public repository (for example `koofi-store`).
3. Upload `index.html`, `styles.css`, and `script.js`.
4. Open repository Settings → Pages.
5. Choose a publishing source/branch and publish.
GitHub Pages can host static websites without separate hosting.

Do not put passwords, payment credentials, IDs, or other sensitive information in this repository.
